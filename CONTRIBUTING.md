# Contribution Guidelines

1. Add desktop wallpapers to the `wallpapers` folder.
2. If the image is processed with ImageGoNord, name the image accordingly i.e., `ign_imagename.png`.
3. To recolor a Nord wallpaper, run `python godracula.py path/to/image.png` (see the README).
4. If the image was downloaded from other sources, link to the image or credit the artist in the README section.
5. If you wish to add mobile wallpapers, please create a new folder if it does not exist.

That's all. Make a PR :)
